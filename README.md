# Aura Resorts - Workshop Repository

Welcome to the **Aura Resorts Workshop** repository! 🌴

This repository is split into two main sub-directories:

```text
Backend workshop frontend/
├── frontend/             # React + Vite + Tailwind CSS Frontend application
│   ├── src/
│   ├── public/
│   ├── package.json
│   └── .env
│
└── backend/              # Supabase Database Schemas & Setup Guides
    ├── SQL queries.txt   # Database table creation scripts
    └── README.md         # Database setup walkthrough
```

---

## 🚀 Quick Start Guide

### 1. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

> **Note:** Without a `.env` file inside `frontend/`, the app runs in **Local Workshop Mode** (in-memory).

### 2. Backend Setup (Supabase)
See the detailed guide in [backend/README.md](file:///d:/project/Backend%20workshop%20frontend/backend/README.md) to set up your Supabase tables and connect your `.env` file.
